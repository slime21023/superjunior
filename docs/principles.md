Copy the full `prin-*` folders you want to use alongside the core skills. You can name a principle explicitly or let the agent select a relevant one. The core skill continues to own the task and its report. Project conventions and authorization apply.

For example, ask: “Use implement-it to fix the empty tag selection and apply prin-tdd.” The implementation report can include the observed failing and passing checks.
