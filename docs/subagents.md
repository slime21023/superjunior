Each role can be used directly in the current session or delegated when authorized. Each agent skill contains its own operating principles. The owner supplies explicit boundaries and verifies delegated results.

| Role | Responsibility |
| :--- | :--- |
| [Scope aligner](/skills/agent-scope-aligner/) | Understand the request, affected code, and done criteria. |
| [TDD implementer](/skills/agent-tdd-implementer/) | Implement and verify a bounded change. |
| [Scientific debugger](/skills/agent-scientific-debugger/) | Investigate and fix a defect with evidence. |
| [Code reviewer](/skills/agent-code-reviewer/) | Review a change or an assigned aspect and report concrete findings. |
| [Git committer](/skills/agent-git-committer/) | Prepare authorized, verified commits. |

Instructions are contained in each agent skill. Host permissions control access. The owner integrates delegated review aspects and determines the overall outcome.
