## Scope a feature

Ask `specify` to define acceptance criteria for CSV export, including handling of empty results and quoted values. Give the accepted specification to `plan-working` if delivery requires multiple ordered changes.

## Verify a bug fix

Ask `debug` to reproduce a tag filter failure and identify the cause. Give the reproduction and expected behavior to `implement-it`, then ask `test-it` to run the reproduction and selected-tag regression checks.

## Record an architecture decision

Ask `explore` to compare direct and queued delivery against latency and reliability requirements. After choosing a direction, give the decision to `design-component` to specify interfaces and failure behavior, and use `document` to record the confirmed decision.
