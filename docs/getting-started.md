## Install the skills

Copy the ten skill folders into the project's [skill directory](/host-integration/#install-the-skills). Start a fresh session and check that all ten skills are available. See [troubleshooting](/host-integration/#if-a-skill-is-not-found) if a skill is missing.

## Give the agent a task

```text
Use debug to find why an empty tag filter hides every item.
Then fix the cause and run a regression check that covers empty and selected tags.
Leave the resulting edits in the working tree.
```

Provide the expected behavior, relevant constraints, and delivery outcome. Keep the diagnosis, changed files, and test results with the task if you continue in another session. See [Skill workflows](/subagents/) for more handoffs.
