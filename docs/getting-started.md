1. Copy the complete skill directories to your [host's skill location](/host-integration/#install-the-skills), then start a new session in the target project.
2. Give the agent a concrete task, such as the [tag filter fix](/examples/#fix-the-tag-filter). State the expected behavior, any regression to avoid, and how far you want delivery to go.
3. Check the response for the result, the command and observed verification, and remaining gaps. If a skill is missing, use the [discovery checklist](/host-integration/#if-a-skill-is-not-found).

For your next task, use the [workflow guide](/workflows/) to find the combination that fits.
