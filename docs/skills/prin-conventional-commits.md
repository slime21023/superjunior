## When to use

Draft or review commit messages when the task or repository calls for Conventional Commits.

## How it changes the work

Choose a type from the actual change. Use fix for a bug fix and feat for a feature. Add a scope when it provides context and the project's configured vocabulary supports it.

For a change that returns all notes when the last tag is cleared, a suitable draft is `fix(filter): show all notes for empty selection`. Use the repository's accepted scope if it defines one.

See [Principles and practices](/principles/) for how to combine it with a core skill.
