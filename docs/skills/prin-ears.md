## When to use

Apply Easy Approach to Requirements Syntax when writing or reviewing requirements with triggers, states, optional features, or failures.

## How it changes the work

Choose a pattern that matches the behavior. Use When for an event, While for a state, Where for an optional feature, and If … then for unwanted behavior. A behavior that always applies starts with the system and its obligation.

When the user requests CSV export, the notes app shall download a parseable CSV. If the query fails, then the notes app shall show an export error and refrain from starting a download. Keep filtered versus all notes pending until the owner decides.
