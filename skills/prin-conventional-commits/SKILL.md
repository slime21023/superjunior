# prin-conventional-commits

## When to apply

Draft or review commit messages when the task or repository calls for Conventional Commits.

## Principles

Choose a type from the actual change. Use fix for a bug fix and feat for a feature. Add a scope when it provides context and the project's configured vocabulary supports it.

## Application notes

Indicate incompatible changes using the required marker or footer. Read any applicable commit configuration or contribution guidance. Draft the message without executing Git actions unless the task authorizes them.

See the [worked example](references/examples.md). See the [source guidance](https://www.conventionalcommits.org/en/).
